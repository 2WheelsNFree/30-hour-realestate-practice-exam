# 30-Hour Real Estate Practice Exam

This is a React-based quiz app designed to help users prepare for the 30-hour real estate licensing exam. It features randomized questions, instant feedback, explanations, and score tracking.

## Features

- Multiple-choice questions with correct answer validation
- Explanations for each question
- Score tracking and progress display
- Customizable question count (10–200)
- Responsive dark-mode UI

## Getting Started

Install dependencies and run locally:

```bash
npm install
npm start
